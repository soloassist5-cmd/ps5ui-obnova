## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/) для своей версии Minecraft.
2. Положи в папку `.minecraft/mods` файл мода для своей версии и [Fabric API](https://modrinth.com/mod/fabric-api) той же версии.
3. Запусти игру через профиль Fabric.

## Банк

Чтобы играть на счёт сервера, открой на главном экране «Привязать профиль к банку», отправь запрос, назови код администратору и задай PIN. После этого кейсы, апгрейдер и награды за мини-игры работают на общий баланс, который также доступен на сайте банка.
